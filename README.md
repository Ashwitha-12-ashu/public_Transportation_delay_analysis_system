# Public Transportation Delay Analysis System 🚍⏱️

A data-driven system that analyzes delays in public transportation to uncover patterns, spot underperforming routes, and measure weather impact on travel time.  
Built to help cities and transit agencies improve reliability and passenger satisfaction.

## Features
- Delay calculation & categorization
- Route performance comparison
- Weather impact analysis
- Hour-wise delay pattern detection
- Visual insights through charts

## Tech Stack
Python • Pandas • NumPy • Matplotlib • MySQL

## Why This Project?
Public transport often suffers from unpredictable delays.  
This system transforms raw timing data into actionable insights that improve planning, reduce delays, and enhance commuter experience.

## Goal
Make transportation efficient, predictable, and data-driven.
